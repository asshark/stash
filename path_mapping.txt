# Stash Path Mapping Configuration
# ==================================
#
# This file defines the mapping between Windows paths and Synology paths
# for database migration.
#
# Format: WINDOWS_PATH|SYNOLOGY_PATH
#
# Rules:
# - One mapping per line
# - Use pipe (|) as separator
# - Windows paths can use either \ or / as separators
# - Lines starting with # are comments
# - Empty lines are ignored
# - Paths are case-insensitive for matching
#
# IMPORTANT NOTES:
# ================
# 1. List longer/more specific paths BEFORE shorter/general ones
#    Example: Put "L:\Videos\Movies" before "L:\Videos"
#
# 2. The Synology paths on the right side should match the paths
#    used in your docker-compose.yml volume mappings
#
# 3. After migration, the database will contain the Synology paths,
#    which will be mapped to container paths via Docker volumes
#
# Example Docker mapping in docker-compose.yml:
#   /volume2/video.xxx.clips/Clips:/data/Clips
#
# This means:
# - Windows path: L:\Clips
# - Synology path (in this file): /data/Clips
# - Actual Synology location: /volume2/video.xxx.clips/Clips
#
# ==================================
# YOUR PATH MAPPINGS
# ==================================
# Edit the mappings below to match your setup
